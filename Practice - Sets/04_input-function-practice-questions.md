# Input Function Practice Questions

Practice these questions to strengthen your understanding of the `input()` function in Python.

---

# Basic Level

### 1. Welcome the User

Take the user's name as input and print a welcome message.

#### Example

```text
Input:
Rahul

Output:
Welcome Rahul!
```

---

### 2. Take and Print Age

Take the user's age as input and print it.

#### Example

```text
Input:
18

Output:
Your age is 18
```

---

### 3. Sum of Two Numbers

Take two numbers as input and print their sum.

#### Example

```text
Input:
10

Output:
30
```

---

### 4. Print City Name in Uppercase

#### Example


### 5. Favorite Programming Language

# Intermediate Level

### 6. Area of a Rectangle

Take the length and breadth of a rectangle as input and calculate its area.

#### Formula

```text
Area = Length × Breadth
```

#### Example

```text
Input:
Length = 10
Breadth = 5

Output:
50
```

---

### 7. Area of a Circle

Take the radius of a circle as input and calculate its area.

#### Formula

```text
Area = π × r²
```

#### Example

```text
Input:
Radius = 7

Output:
153.94
```

- Principal
- Rate
- Time

as input and calculate Simple Interest.
