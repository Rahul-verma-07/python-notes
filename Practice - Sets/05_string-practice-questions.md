# String Practice Questions

Practice these questions to strengthen your understanding of Python strings.

---

# Basic Level

### 1. Find the Length of a String

Take a user's name as input and print its length.

#### Example

```text
Input:
Rahul

Output:
5
```

---

### 2. Count Occurrences of a Character

Take a string as input and count how many times the letter `'a'` appears.

#### Example

```text
Input:
banana

Output:
3
```

---

### 3. Convert String to Uppercase

Take a string as input and convert it to uppercase.

#### Example

```text
Input:
hello world

Output:
HELLO WORLD
```

---

### 4. Replace Spaces with Underscores

Take a string as input and replace all spaces with `_`.

#### Example

```text
Input:
hello world

Output:
hello_world
```

---

### 5. Check String Prefix

Check whether a string starts with `"Hello"`.

#### Example

```text
Input:
Hello Rahul

Output:
True
```

---

# Intermediate Level

### 6. Reverse a String

Reverse a string without using slicing (`[::-1]`).

#### Example

```text
Input:
Python

Output:
nohtyP
```

---

### 7. Check Palindrome

Check whether a string is a palindrome.

A palindrome reads the same forwards and backwards.

#### Example

```text
Input:
madam

Output:
Palindrome
```

---

### 8. Count Vowels and Consonants

Count the total number of vowels and consonants in a string.

#### Example

```text
Input:
Python

Output:
Vowels: 1
Consonants: 5
```

---

### 9. Find the First Non-Repeating Character

Find the first character that appears only once in a string.

#### Example

```text
Input:
aabbcdde

Output:
c
```

---

### 10. Remove Duplicate Characters

Remove all duplicate characters from a string while keeping the first occurrence.

#### Example

```text
Input:
programming

Output:
progamin
```
