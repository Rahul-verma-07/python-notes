- Addition

Division = 2.0

### 5. Calculate Simple Interest

Calculate Simple Interest using the formula:

```text
SI = (P × R × T) / 100
```

Where:

- P = Principal
- R = Rate
- T = Time

#### Example

```text
Input:
P = 1000
R = 5
T = 2

Output:
100
```
