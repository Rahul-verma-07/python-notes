# Tuple Practice Questions

Practice these questions to strengthen your understanding of Python Tuples.

---

# Basic Level

### 1. Create a Tuple

Create a tuple containing 5 numbers and print it.

#### Example

```text
Output:
(10, 20, 30, 40, 50)
```

---

### 2. Print the First and Last Element

Print the first and last element of a tuple.

#### Example

```text
Input:
(10, 20, 30, 40, 50)

Output:
10
50
```

---

### 3. Find the Length of a Tuple

Print the total number of elements in a tuple.

#### Example

```text
Input:
(1, 2, 3, 4, 5)

Output:
5
```

---

### 4. Count Occurrences of an Element

Count how many times a specific element appears in a tuple.

#### Example

```text
Input:
(1, 2, 3, 2, 4, 2)

Find:
2

Output:
3
```

---

### 5. Find the Index of an Element

Find the index of a given element in a tuple.

#### Example

```text
Input:
(10, 20, 30, 40)

Find:
30

Output:
2
```

# Intermediate Level

### 6. Convert Tuple to List and Add an Item

Convert a tuple into a list, add a new item, and print the updated list.

#### Example

```text

```

### 7. Find Maximum and Minimum Element

Find the largest and smallest element in a tuple.

#### Example

```text

(10, 5, 20, 50, 2)

Maximum = 50
Minimum = 2
```

---

### 8. Check Whether an Item Exists

Check whether a specific item exists in a tuple.

#### Example

```text
Input:
(10, 20, 30, 40)

20

Output:
Found
```

---

### 9. Unpack a Tuple into Variables

Unpack the values of a tuple into separate variables.

#### Example

```python
t = (10, 20, 30)

a, b, c = t
```

#### Output

```text
a = 10
b = 20
c = 30
```

# Challenge Questions

### 11. Reverse a Tuple

Create a new tuple with elements in reverse order.

#### Example

```text
Input:
(1, 2, 3, 4)

Output:
(4, 3, 2, 1)
```

---

### 12. Merge Two Tuples

Combine two tuples into one.

#### Example

```text
Tuple 1:
(1, 2, 3)

Tuple 2:
(4, 5, 6)

Output:
(1, 2, 3, 4, 5, 6)
```

---

### 13. Find Duplicate Elements

Find all duplicate elements in a tuple.

#### Example

```text
Input:
(1, 2, 3, 2, 4, 1)

Output:
(1, 2)
```

---

### 14. Count Even and Odd Numbers

Count the number of even and odd elements in a tuple.

#### Example

```text

```
