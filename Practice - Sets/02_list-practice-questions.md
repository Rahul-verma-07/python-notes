# List Practice Questions

Practice these questions to strengthen your understanding of Python Lists.

---

# Basic Level

### 1. Create and Print a List

Create a list containing 5 fruit names and print the list.

#### Example

```text
Output:
['Apple', 'Banana', 'Mango', 'Orange', 'Grapes']
```

---

### 2. Add an Element to a List

Add a new fruit to an existing list.

#### Example

```text
Before:
['Apple', 'Banana', 'Mango']

After:
['Apple', 'Banana', 'Mango', 'Orange']
```

---

### 3. Remove an Element from a List

Remove a specific item from a list.

#### Example

```text
Before:
['Apple', 'Banana', 'Mango']

After:
['Apple', 'Mango']
```

---

### 4. Find the Length of a List

Print the total number of elements present in a list.

#### Example

```text
Input:
[10, 20, 30, 40]

Output:
4
```

---

### 5. Sort a List

Sort a list of numbers in ascending order.

#### Example

```text
Input:
[4, 2, 1, 3]

Output:
[1, 2, 3, 4]
```

---

# Intermediate Level

### 6. Find the Largest and Smallest Number

Find the maximum and minimum value from a list.

#### Example

```text
Input:
[10, 50, 20, 5, 70]

Output:
Largest = 70
Smallest = 5
```

---

### 7. Count Occurrences of an Element

Count how many times a specific number appears in a list.

#### Example

```text
Input:
[1, 2, 2, 3, 2, 4]

Find:
2

Output:
3
```

---

### 8. Remove Duplicate Elements

Remove all duplicate values from a list.

#### Example

```text
Input:
[1, 2, 2, 3, 3, 4]

Output:
[1, 2, 3, 4]
```

---

### 9. Merge Two Lists Without Using `+`

Combine two lists without using the `+` operator.

#### Example

```text
List 1:
[1, 2, 3]

List 2:
[4, 5, 6]

Output:
[1, 2, 3, 4, 5, 6]
```

---

### 10. Find the Second Largest Number

Find the second largest number in a list.

#### Example

```text
Input:
[10, 50, 30, 70, 20]

Output:
50
```

---
