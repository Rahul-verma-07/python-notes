# ⭐ Bonus Challenge Questions

## Challenge 1 — Number Guessing Game

Create a menu-driven number guessing game where:

- The computer stores a secret number.
- The user keeps guessing until the correct number is entered.
- Display whether the guess is **Too High**, **Too Low**, or **Correct**.
- Count the total number of attempts.

---

## Challenge 2 — Student Result System

Create a function that accepts marks of **five subjects** and returns:

- Total Marks
- Percentage
- Grade
- Pass/Fail Status

Use functions wherever possible.

---

## Challenge 3 — Scientific Calculator

Create a menu-driven calculator using functions.

The calculator should support:

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Square
- Cube
- Square Root (without using external libraries)

---

## Challenge 4 — Number Analyzer

Write a function that determines whether a number is:

- Even or Odd
- Positive or Negative
- Prime or Composite
- Armstrong or Not
- Perfect or Not

Display all results together.

---

## Challenge 5 — Pattern Generator

Create a menu-driven pattern generator that prints any one of the following patterns based on the user's choice.

Example patterns:

```text
*
**
***
****
*****
```

```text
*****
****
***
**
*
```

```text
1
12
123
1234
12345
```
