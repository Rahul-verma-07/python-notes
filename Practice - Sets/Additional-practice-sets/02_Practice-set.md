# Question 1 — Least Common Multiple (LCM)

## Problem

Write a program to find the **Least Common Multiple (LCM)** of two numbers using your own GCD function.

> **Do not use** `math.lcm()`.

### Example

#### Input

```text
12
18
```

#### Output

```text
36
```

# Question 5 — Multiplication Table

## Problem

Create a function:

```python
table(number, upto)
```

that prints the multiplication table of a given number up to the specified limit.

### Example

```python
table(7, 10)
```

### Output

```text
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
...
7 x 10 = 70
```

# Question 7 — Perfect Number

## Problem

Write a function that checks whether a number is a **Perfect Number**.

> A Perfect Number is a positive integer that is equal to the sum of its proper divisors (excluding itself).

### Example

#### Input

```text
28
```

#### Output

```text
True
```
