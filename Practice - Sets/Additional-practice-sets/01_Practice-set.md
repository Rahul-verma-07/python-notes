# Practice Set 01

# Question 1 — Grade Calculator

## Problem

Write a function `grade(marks)` that returns the student's grade according to the following table.

| Marks | Grade |
|-------:|:-----:|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| Below 60 | F |

### Requirements

- Create a function.
- Return the grade.
- Do not print inside the function.

### Example

#### Input

```text
95
```

#### Output

```text
A
```
