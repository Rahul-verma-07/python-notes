# Conditional Expressions in Python

Conditional expressions are used to make decisions in a program.

In Python programming, we often need to execute certain instructions only when specific conditions are met.

Conditional expressions help a program choose different actions based on different situations.

---

# Why Conditional Expressions?

Suppose we want to check whether a student has passed an exam.

```text
If marks are greater than or equal to 40:
    Print "Passed"

Otherwise:
    Print "Failed"
```

This type of decision-making is done using conditional expressions.
