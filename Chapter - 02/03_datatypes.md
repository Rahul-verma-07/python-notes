# Data Types in Python

Data types define the type of value stored in a variable.

Primarily, Python has the following data types:

1. Integer
2. Floating Point Number
3. String
4. Boolean
5. None Type

---

## 1. Integer Data Type

Integers are whole numbers without decimal points.

## Example

```python
a = 7
print(a)
```

## Output

```text
7
```

---

## 2. Floating Point Data Type

Floating point numbers contain decimal values.

## Example

```python
b = 3.14
print(b)
```

## Output

```text
3.14
```

---

## 3. String Data Type

Strings are used to store text data.

Strings are written inside single quotes `' '` or double quotes `" "`.

## Example

```python
c = "Rahul"
print(c)
```

## Output

```text
Rahul
```

---

## 4. Boolean Data Type

Boolean values can store only two values:

```text
True
False
```

## Example

```python
d = 2 < 3
print(d)
```

## Output

```text
True
```

---

## 5. None Data Type

`None` is used when a variable stores no value.

## Example

```python
e = None
print(e)
```

## Output

```text
None
```

---

# Complete Example

```python
a = 7
# Integer

b = 3.14
# Floating Point Number

c = "Rahul"
# String

d = 2 < 3
# Boolean

e = None
# None Type

print(a)
print(b)
print(c)
print(d)
print(e)
```

## Output

```text
7
3.14
Rahul
True
None
```

---

# Important Note

Python is a fantastic programming language because it automatically identifies the data type of variables for us.

This feature is known as **Dynamic Typing**.
