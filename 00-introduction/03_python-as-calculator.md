## Python as a Calculator

Python can also be used as a simple calculator directly in the terminal.

To start Python in the terminal, type:

```bash
python
```

After typing `python`, you can perform mathematical calculations like this:

```python
>>> 5 + 3
8

>>> 10 * 2
20
```

This interactive mode of Python is called **REPL**.

### REPL Meaning

```text
R → Read
E → Evaluate
P → Print
L → Loop
```

### Explanation

- **Read** → Python reads the command entered by the user.
- **Evaluate** → Python evaluates (processes) the command.
- **Print** → Python prints the result on the screen.
- **Loop** → Python waits for the next command.
