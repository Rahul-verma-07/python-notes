# Strings in Python

A string is a data type in Python that is used to store a sequence of characters.

Strings are enclosed inside quotes.

---

# Types of Strings in Python

Python allows strings to be written using:

1. Single Quotes `' '`
2. Double Quotes `" "`
3. Triple Quotes `''' '''`

---

# Example

```python
a = 'Hello'
# Single Quotes

b = "World"
# Double Quotes

c = '''Hello World!'''
# Triple Quotes

print(a)
print(b)
print(c)
```

---

# Output

```text
Hello
World
Hello World!
```

---

# Explanation

## 1. Single Quotes

Strings can be written using single quotes.

## Example

```python
a = 'Hello'
```

---

## 2. Double Quotes

Strings can also be written using double quotes.

## Example

```python
b = "World"
```

---

## 3. Triple Quotes

Triple quotes are mainly used for:

- Multi-line strings
- Long text

## Example

```python
c = '''Hello World!'''
```

---

# Multi-line String Example

```python
text = '''
Python is easy to learn.
Python is beginner-friendly.
'''

print(text)
```

---

# Output

```text
Python is easy to learn.
Python is beginner-friendly.
```

---

# Important Note

In Python:

```python
'Hello'
```

and

```python
"Hello"
```

both are valid strings.

The choice depends on the programmer's preference.
