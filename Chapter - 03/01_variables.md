# Variables in Python

A variable is the name given to a memory location in a program.

Variables are used to store data in Python.

## Example

```python
num1 = 7
num2 = 8
# "num1" & "num2" are variables

print(num1)
print(num2)
# Printing the values stored in variable "num1" & "num2"
```

## Output

```text
7
8
```
