# Comments in Python

Comments are used to write notes or explanations in a program that the programmer does not want Python to execute.

They help make the code easier to understand and improve readability.

---

## Types of Comments in Python

### 1. Single Line Comment

A single line comment is written using the `#` symbol.

## Syntax

```python
# This is a single line comment
```

## Example

```python
# Printing Hello World
print("Hello World")
```

> `#` is known as the **Hash** or **Pound Symbol** and is used for single line comments.

---

### 2. Multi-Line Comment

Multi-line comments are written using triple double quotes `""" """`.

## Syntax

```python
"""
This is a
multi-line comment
"""
```

## Example

```python
"""
This program prints
Hello World on the screen
"""

print("Hello World")
```

> Triple double quotes `""" """` are used for writing multi-line comments in Python.
